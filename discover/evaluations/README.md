# Evaluations

## Elnevezési konvenció

`<model>-evaluation-<sorszám>.md`

- `sonnett-evaluation-*.md` - Claude Sonnet értékelések
- `opus-evaluation-*.md` - Claude Opus értékelések

## Cél

Külső perspektíva és kritikai gondolkodás az ötletekről, specifikációkról - a "devil's advocate" szerepben.
